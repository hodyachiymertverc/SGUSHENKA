📈 Уровни кликера

        
Диапазоны считаются от суммарно заработанных банок (не от текущего баланса).

🏆 Рекорды — лёгкий уровень

        
Отдельная таблица рекордов для лёгкого режима змейки.

        
        

      


      

        
🏆 Рекорды — сложный уровень

        
Отдельная таблица рекордов для сложного режима змейки (с бомбами).

        
        

      


      

        
📈 Уровни змейки

        
Диапазоны считаются от суммарно пойманных банок за все игры (обе сложности вместе).

        

        
        

      


      

        
🏆 Достижения змейки

        
Условие проверяется автоматически по накопленной статистике игрока в змейке.

        

        
        

      

    


    
    

      

        
🏆 Управление рекордами

        
Общая таблица рекордов Doodle-прыжков (по максимальной высоте за игру).

        
        

      


      

        
🥫 Статистика игроков

        
Можно изменить никнейм и любую накопленную статистику игрока вручную.

        
        

      


      

        
📈 Уровни Doodle-прыжков

        
Диапазоны считаются от суммарной высоты, набранной за все игры.

        

        
        

      


      

        
🏆 Достижения Doodle-прыжков

        
Условие проверяется автоматически по накопленной статистике игрока в Doodle-прыжках.

        

        
        

      

    


    
    

      

        
🏆 Управление рекордами

        
Общая таблица рекордов (по числу побед).

        
        

      


      

        
🎮 Статистика игроков

        
Можно изменить никнейм, победы/поражения/ничьи и текущую серию побед вручную.

        
        

      


      

        
📈 Уровни крестиков-ноликов

        
Диапазоны считаются от общего числа побед игрока.

        

        
        

      


      

        
🏆 Достижения крестиков-ноликов

        
Условие проверяется автоматически по накопленной статистике игрока.
